# Kongeuni KT Maker

콩으니의 Windows용 **카카오톡 테마 편집기**입니다.
화면 미리보기에서 요소를 선택하고, 색상과 이미지를 바꾼 뒤 안드로이드 APK와 iOS 테마(.ktheme)를 만들 수 있습니다.

![테마 에디터 미리보기](docs/images/editor-preview.png)

미리보기 이미지는 기능 확인에 사용한 개발 화면으로, 일부 이전 표시명이 보일 수 있습니다.

## 주요 기능

- 친구·채팅 목록·채팅방·더보기·잠금화면 등 화면별 미리보기
- 같은 색상을 묶어서 편집하고 투명도 조절
- 기본 프로필 최대 3종, 배경·아이콘·말풍선 이미지 교체
- 나인패치 늘림/내용 영역 드래그 편집과 실시간 미리보기
- 나인패치 좌표 전체 복사·붙여넣기 및 이미지 교체 시 좌표 유지
- 실행취소·다시실행, 프로젝트 저장·불러오기
- 테마 이름·아이콘·버전·앱 식별자 설정과 APK 내보내기
- 같은 프로젝트로 iOS 테마(.ktheme) 내보내기 — 추가 설치 없이 바로 생성

![말풍선 나인패치 편집](docs/images/nine-patch-preview.png)

## 개발 환경에서 실행

Node.js와 npm을 설치한 뒤 실행합니다.

```sh
npm ci
npm start
```

APK 빌드에는 **JDK 21**, Android SDK Platform 35와 Build Tools 35.0.0이 필요합니다.
Android Studio SDK Manager에서 구성하고 라이선스를 확인하세요.
`ANDROID_HOME`으로 SDK 위치를 지정할 수 있습니다.
Gradle과 의존성은 첫 빌드 때 내려받으므로 인터넷 연결이 필요합니다.

## iOS 테마 만들기

상단의 **iOS 테마 만들기** 버튼을 누르면 `.ktheme` 파일이 만들어집니다.
JDK나 Android SDK가 필요 없습니다. 안드로이드용으로 편집한 색상과 이미지가 iOS 형식으로 자동 변환됩니다.

- xxhdpi 이미지를 iOS @3x로, 축소해서 @2x로 저장합니다.
- 말풍선 나인패치의 늘림 영역과 내용 영역을 iOS 캡 인셋과 텍스트 여백으로 바꿉니다.
- `#AARRGGBB` 색상은 iOS의 색상 + 투명도 값으로 나눕니다.
- 테마 ID는 앱 식별자를 사용하고, 버전은 버전 표시명의 숫자 부분을 사용합니다. 숫자가 없으면 `1.0.0`을 사용합니다.

아이폰에서는 `.ktheme` 파일을 카카오톡으로 열어 적용합니다.

## APK 빌드 전 점검

APK 만들기를 누르면 JDK 21, SDK 폴더, Platform 35, Build Tools 35.0.0, SDK 라이선스를 먼저 확인합니다.
빠진 항목이 있으면 Gradle 빌드를 시작하기 전에 한 번에 모두 알려줍니다.

## Windows 실행본 만들기

```sh
npm run package:exe
```

`dist/release/Kongeuni-KT-Maker-0.1.0-windows-x64.exe`가 생성됩니다.
릴리즈의 EXE 하나를 내려받아 실행하면 됩니다. 설치나 ZIP 압축 해제가 필요 없습니다.
첫 실행 시 내부 파일을 임시 폴더에 풀기 때문에 잠시 시간이 걸릴 수 있습니다.

## 프로젝트와 기본 정보

작업은 `.ktstudio` 파일로 저장합니다. APK 빌드 전에는 자동 백업도 생성됩니다.
실행취소 기록은 현재 실행 중에만 유지됩니다.

새 프로젝트의 기본 제작자는 `콩으니`, 버전 표시명은 `Kongeuni`,
앱 식별자는 `KongeuniThema.NewThema`입니다. 배포할 테마마다 식별자를 바꿔주세요.

## 참고

Android 26.1.0 샘플 리소스를 기반으로 제작했습니다.
미리보기와 실제 카카오톡의 일부 고정 UI는 버전·기기에 따라 다를 수 있습니다.
미리보기용 서비스 아이콘에는 직접 그린 벡터가 포함됩니다.

이 프로젝트는 Kakao의 공식 제품이 아닙니다.
포함된 Kakao 샘플·캐릭터 리소스의 권리는 해당 권리자에게 있습니다.
사용자가 추가하는 이미지와 로고는 각 권리자의 사용 조건을 따라주세요.
